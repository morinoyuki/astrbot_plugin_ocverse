# astrbot_plugin_ocverse · 分身的世界

**把群聊变成一个会变动的世界 —— 每人一个 OC 分身,在里面生活、遭遇、互动,并随世界一起穿越。**

- 🧑‍🎨 **自定义 OC**:一人一角色,自定义姓名 / 性别 / 性格标签 / 背景设定,可上传头像
- 🎲 **每日随机事件**:活跃时段内随机时刻触发,由 LLM 结合**世界观 + 性格 + 属性 + 记忆**生成,给出 2~4 个抉择,抉择改变属性与人生
- 🌀 **世界变动**:小概率全员穿越 —— 按比例随机选中「玩家自设的沉眠世界」或由 LLM 现场生成新世界
- 📖 **世界书**:玩家可以 `定义世界` 把自设世界存进列表;**只有穿越过的世界才能自由穿越**(自设世界也要等降临后解锁)
- 😺 **群友互动 / NPC**:@ 群友打招呼、闲聊、请客、切磋、送礼、吐槽,也支持**自定义互动**;每个世界有独特 NPC 与独有事件灵感
- ⚡ **主动行动**:健身 / 练习 / 打怪 / 自由冒险——你可以**主动让分身去做事**,属性、金币、心情随之变化,还小概率触发机缘彩蛋;体力与每日限次作为平衡(赚金币另有专门的`兼职`世界打工)
- ⛓ **特殊状态**:事件/冒险可能让分身陷入**囚禁、束缚、被困**等无法自由行动的状态——此时不能练习/健身/打怪、不能开启穿越、不能主动与人搭话、连每日小任务也不能领/做;**只能靠『冒险』挣扎脱困、找特殊NPC求助(能否帮上忙由AI判断)、群友互动来救TA(是否救成也由AI判断)**,或被小概率**世界变动**一并卷走解除;状态会显示在角色卡上
- 🎒 **背包 / 物品**:冒险、事件、委托、兼职都可能让分身**获得或失去物品**——物品进背包可查(`背包`)、可丢(`背包 丢弃`),AI 在结算时按剧情自然给出/消耗;委托还支持「取得某物」这类要拿物品回来交差的目标
- 📌 **委托任务(闭环)**:每日委托由**设施发布、有明确委托人(组织/NPC/临时人物)**,由 1~3 个当前系统真能做到的**可验证步骤**(冒险/找NPC/生活角色/群友互动/兼职/取得物品)构成,**一步步做完(进度会持久化)再向委托人交付**拿悬赏——交付场景严格锁定委托人出场,不会把成果送错人
- 🗣 **自定义世界 NPC**:给(当前/指定)世界手工安插 NPC,`npc <名字>` 就能与 TA 互动,把世界变成你的
- 🎭 **持久生活角色**:用「`分身 定义角色 <名字> <描述>`」创造不属于任何真人的**群级持久角色**——像群友一样参与生活事件、被卷入世界变动、能上传头像、能与 TA `分身 找 <名字>` 互动并发展关系/告白/结婚;世界NPC也各自有日常行踪、怪癖与口头禅,且世界人口会**不定时流动**(系统NPC会搬家离开/换工作/迎来新面孔,像真实社会一样人来人往)
- 🏙 **世界生活基建**:每个世界由 LLM 按题材生成 **20~28 个**种类丰富的基础设施(补给/住宿/餐饮/医疗/据点等生存必需,**外加茶馆酒馆/戏台剧场/温泉澡堂/公园花园/观景看台/夜市市集/约会胜地等社交娱乐场所**,其中至少2处可打工)、8~14 个有日常行踪与小怪癖的 **NPC**、一段可推进的**世界主线**,以及**可供购置/回家休整的房产**(按攒钱难度定价,越贵回家恢复越多)——皆贴合世界观,非模板
- 🏮 **设施可交互**:社交/娱乐/约会类设施用「`分身 去 <设施名> [想做什么]`」可随时**光顾消遣,触发一段小事件剧情**(每天每家限1次);打工中被拦
- 🧠 **记忆系统**:每人一份时间线人生日志 + 轻量语义向量检索(默认**零依赖哈希词向量**,不加载模型、不吃 NAS 性能;可选 OpenAI 兼容 embedding API),长期记忆超量自动压缩成「核心记忆」;另有**世界记忆**记录全局大事/主线进展/NPC与设施流转,`分身 世界` 可览,并注入各生成场景保持世界连贯
- 🖼️ **IM 聊天卡片**:纯 Pillow 服务端渲染,**无桌面、无浏览器依赖**,适配 Docker / 低性能 NAS
- 📉 **性能友好**:SQLite(WAL)+ 单进程 + LLM 并发信号量限制;LLM 不可用时自动降级到内置内容,**离线也能玩**

## 快速上手(5分钟开玩)

**第一步 · 铺世界**(管理员):发送 `分身 初始化世界`,或带一句设定,如:
`分身 初始化世界 蒸汽朋克飞空艇都市,阶级森严,天空海盗出没`——AI 会生成世界档案、8~14 位有日常行踪的 NPC、20~28 处可去的设施(含能打工的与社交娱乐约会场所)、一条世界主线与可购置的房产。

**第二步 · 降生**(每个群友):`分身 创建 秋山澪 看似高冷的图书馆管理员,其实怕鬼`——AI 整理人设并分配六维属性;再 `分身 设置头像` + 图片立绘。

**第三步 · 过日子**:
- 每天活跃时段会随机发生**事件**:主动事件到点推送,被动伏笔在有人说话时引爆(冲着说话的人来);事件卡下方有 1~3 个选项,**回复事件卡**发 `分身 选择 <编号>` 抉择——属性、金币、人生走向随之改变
- 与群友 `分身 与 @某人 闲聊/请客/切磋`、找生活角色 `分身 找 绫波 喝茶`,好感与羁绊在日常中生长;好感到位会**自然触发告白/求婚**(无指令)
- 搞点关系:`分身 关系 @老徐 爸爸`——AI 会以老徐的性格决定认不认你这个儿子
- 想主动做事:`练习/健身/兼职/打怪/冒险`,体力与每日次数平衡收益

**第四步 · 等世界变**:每天有小概率**世界变动**,全员被卷进新世界(自设世界可能降临);穿越过的世界可随时 `分身 穿越世界` 回去。

**长期玩点**:人生时间线日志 + 语义记忆检索(`分身 日志` / `分身 回忆 关键词`)、核心记忆自动压缩、世界人口流动、主线推进、买房回家——适合一个群玩几个月。

## 世界变动规则

1. 每天生成日程时,按「变动概率」安排一次隐藏的世界变动时刻(默认 8%/日,可调)
2. 触发时:以「用户世界份额」(默认 40%)随机决定——
   - 选中**已定义但尚未到达**的玩家自设世界 → 它降临,并解锁自由穿越
   - 否则 LLM 现场生成一个全新世界(自动避开重名)
3. 全员获得「次元旅者」称号与少量奖励;世界列表中沉眠世界标记 🔒,穿越过即可随时回去

## 时间与调度(长期运行设计)

- **凌晨 4 点 = 游戏日切**(可配):每天进入该时刻时,自动生成并持久化当日全部计划——晨报、若干事件(时刻随机)、世界变动骰,同时进行每日重置(体力恢复)。4 点前的深夜仍算前一天
- **主动事件**:到计划时刻由调度循环(分钟级对齐)主动触发并发送事件卡
- **被动事件(伏笔)**:到计划时刻只"埋下伏笔"不推送;当群里有任何动静(有人说话)时引爆——事件**冲着说话的人来**,更有代入感;活跃时段结束仍无人引爆则转主动兜底推送
- **停机补偿**:错过的事件在恢复后按计划时刻顺序补触发(每分钟每群最多 3 条);彻底错过的天不补发事件
- **长期记忆**:事件/互动持续沉淀为记忆,超过阈值自动压缩为「核心记忆」,时间线完整保留,适合玩几个月

## 安装

```bash
# Docker / NAS 部署:把本目录放入 AstrBot 的 data/plugins/ 后,在 WebUI 安装依赖
pip install -r requirements.txt   # pillow / numpy / aiohttp
```

- 需要在 AstrBot WebUI 配置好一个 LLM 提供商(OpenAI 兼容);也可在插件配置里单独指定 `provider_id`
- 渲染字体:插件自带 `fonts/`(OPPOSans + NotoColorEmoji + Symbola,含 emoji/符号回退链);也可用环境变量 `OCVERSE_FONT` 指定任意 CJK 字体,或放进 `fonts/` 自动探测(与运行目录无关)
- 完全无桌面/无浏览器依赖;AstrBot 本体不装 Chromium 也能正常出图

## 后台管理页

管理页直接集成在 AstrBot Dashboard(4.27+),无独立端口、鉴权走 Dashboard 登录态:

- 打开 Dashboard → 「插件」→ 分身的世界卡片 → **页面** 进入「后台管理」(插件配置 `admin_enable` 可关闭)
- 页面内所有请求经 bridge SDK 自动携带 Dashboard 登录态,无需任何密钥/令牌
- 功能:
  - **角色**:查看/编辑全部属性(名字/设定/标签/金币/体力/心情/六维/flags)、编辑羁绊、删除角色
  - **世界**:切换编辑任意世界(含沉眠中):档案(名字/题材/描述/规则/独特之处)、**设施整表编辑**(含打工职业)、NPC 整表编辑/增删(含系统 NPC)
  - **事件**:查看待抉择与历史事件,一键强制平淡收场
  - **日志/记忆**:按角色筛选分页浏览,勾选删除记忆
  - **配置**:每日事件数/世界变动概率/用户世界份额/穿越冷却等群参数
  - **操作**:手动触发事件/世界变动/晨报(结果照常推送群里)

## 配置(节选)

| 配置 | 默认 | 说明 |
|---|---|---|
| `provider_id` | 空 | LLM 提供商,留空用会话默认 |

| `passive_event_share_percent` | 40 | 被动事件(伏笔)比例,其余为到点主动推送 |
| `event_min` / `event_max` | 2 / 4 | 每日事件数范围 |
| `active_start_hour` / `active_end_hour` | 9 / 23 | 活跃时段 |
| `shift_daily_percent` | 8 | 世界变动概率(%/日) |
| `user_world_share_percent` | 40 | 变动时选中自设世界的比例 |
| `travel_cooldown_hours` | 6 | 自由穿越冷却 |
| `morning_brief` | true | 每日晨报卡片 |
| `card_theme` | dark | dark / light / ocean / sakura |
| `knowledge_collect_enabled` | true | 定时联网/LLM 采集著作素材入知识库(供所有生成注入) |

| `knowledge_base_max` | 40 | 每群素材库容量上限 |
| `embedding_backend` | astrbot | 记忆语义向量后端:astrbot = 用 AstrBot 内置 Embedding 提供商(WebUI 配置即可);hash = 零依赖哈希词向量 |

| `max_npcs_per_world` | 20 | 每个世界手动添加的 NPC 数上限 |

完整项见 `_conf_schema.json`。

## 数据与性能

- 数据:`data/AstrBot数据目录/astrbot_plugin_ocverse/` 下 `ocverse.sqlite3`(WAL)+ `avatars/` + `tmp/`(卡片临时文件自动清理)
- 语义记忆默认使用**字符 n-gram 哈希词向量**(256 维,纯 Python 余弦检索),不下载模型、不占显存,数百条记忆检索在 NAS 上毫秒级
- 可选配置 embedding API(OpenAI 兼容 `/embeddings`)后自动升级真语义向量,失败自动回退

## 结构

```
main.py                 AstrBot 插件入口:指令、后台调度、主动播报
ocverse/
  config.py             常量(属性/称号/羁绊/默认世界)
  models.py             数据类
  db.py                 SQLite 存储层(WAL)
  embedder.py           哈希词向量 + 可选 API embedding
  memory.py             记忆系统(检索/去重/核心记忆压缩)
  llm_engine.py         LLM 封装(宽容 JSON 解析 + 全链路 fallback)
  game.py               玩法引擎(日程/事件/互动/变动/穿越/成长)
  avatar_store.py       分身头像存取
  imcard/               IM 聊天卡片渲染引擎(纯 Pillow;基于作者 life_sim 的
                        im_render 改造,新增属性条/选项卡/头像头部/面板等行类型)
fonts/                  自带字体(OPPOSans / NotoColorEmoji / Symbola)
tests/smoke_test.py     冒烟测试(venv 可独立运行)
```
